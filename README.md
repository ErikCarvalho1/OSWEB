# ⚙️ Sistema de Automação de Processos

Uma aplicação web desenvolvida para **automatizar processos**, reduzir tarefas repetitivas e tornar o fluxo de trabalho mais **rápido, organizado e eficiente**.

O sistema foi criado com foco em produtividade, oferecendo uma interface intuitiva e recursos que simplificam o gerenciamento das operações do dia a dia.

---

## 🚀 Funcionalidades

- 📋 Gerenciamento de processos
- ⚡ Automação de tarefas repetitivas
- 📊 Organização de informações em tempo real
- 🔍 Pesquisa e consulta de registros
- 📝 Cadastro, edição e exclusão de dados
- 📱 Interface responsiva
- 🔒 Estrutura preparada para autenticação de usuários

## 💻 Como Executar

Clone o repositório:

```bash
git clone https://github.com/ErikCarvalho1/OSWEB.git
```

Entre na pasta do projeto:

```bash
cd OSWEb
```

Abrir o arquivo:

```bash
index.html
```

## 🚀 Publicando no Firebase

Caso deseje realizar um novo deploy da aplicação:

```bash
firebase login
firebase init hosting
firebase deploy
```
